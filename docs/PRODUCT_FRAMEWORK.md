# StratOS 30人核心版 · 产品框架（基于反向推演修正）

> **⚠ 已 superseded：** 用户明确拒绝「阉割模块」路线。请以 [EVOLUTION_PLAN.md](./EVOLUTION_PLAN.md) · [PRD.md](./PRD.md) v1.2 · 完整 v5.4 分期交付为准。本文档仅作历史参考。

**产品定位：** 面向30人核心管理层的战略推演工具，非全员系统  
**用户定义：** CEO + 事业部负责人 + 项目经理 + 核心职能（战略/财务/HR/市场）+ 高潜骨干  
**核心主张：** 让30个人的战略共识，从"老板知道"变成"大家都知道"  
**使用方式：** 在线录入为主、Excel导入为辅、季度更新、会议驱动  
**修正日期：** 2026-06-14

> 完整框架见项目初始化时的产品规格。本文档为 StratOS 30人核心版的权威产品定义。

## 三层架构

1. **战略共识（Strategic Alignment）** — 使命愿景、年度 BSC、个人 OKR 关联
2. **战略执行（Strategic Execution）** — 项目群 V1-V10、假设管理、承诺追踪、预算
3. **战略健康（Strategic Health）** — 四维度红绿灯、关键预警、健康度评分、一页纸复盘

## 五大模块（MVP）

| 模块 | 代号 | 说明 |
|------|------|------|
| 战略共识 | StratAlign | BSC 地图、OKR 对齐树、个人一页纸 |
| 项目追踪 | StratTrack | V1-V10 看板、假设管理、关键预警 |
| 承诺管理 | StratCommit | 个人承诺录入、提醒、兑现率 |
| 健康度 | StratHealth | 四维度红绿灯、综合评分、8 个 KPI |
| 复盘与报告 | StratReview | GRAI+KPT、季度快照、AI 顾问 |

## 五种角色

`ceo` · `vp` · `pm` · `staff` · `observer`

## 三大方针

- **投资驱动增长** — 钱花在刀刃上
- **创新引领** — 别抄别人，自己做出好东西
- **兑现承诺** — 说到做到，别放空炮

## 实施路线

- **Phase 1（MVP，2个月）：** 用户系统 + StratAlign + StratTrack + StratHealth + AI 顾问
- **Phase 2（1个月）：** StratCommit + StratReview + 版本对比 + 资料库
- **Phase 3（持续）：** 反馈优化、Excel 导入、移动端适配
