## 1. 一句话

**StratOS 是给 CEO、董事会和高管用的「战略沙盘」**——把要打什么仗、打到哪、哪里有风险，放在一屏看清；**每年年中、年底两次战略会**做版本快照对比，找变化、看战略稳健性。

**不是：** ERP · 全员 OKR · 日常项目管理。

---

## 2. 服务对象

- 公司约 **300 人**，核心深度用户 **约 30 人**
- 独立 Web 站点；数据在线填 + 报告上传 + 偶尔 Excel；**不**实时接 ERP

---

## 3. 战略逻辑（骨架）

```
三支柱 Doctrine     → 精神：Invest / Innovate / Deliver（审计，不打分）
四个满意 + BSC      → 底线：战略保障（财务维 = 股东满意 = FPA 主锚点）
FPA 财务脊梁        → 数字：B-A-F · 四品牌 P&L · Vx 预算 · 现金流 · 假设驱动
OKR                → 牵引：季度执行（KR 绑 budget_tag）
Vx + 假设 + 承诺    → 载体：项目与信任
健康度 + 稳健性      → 战果：四灯 + StratRobust（含 FPA 偏差与 runway）
```

---

## 4. 核心三件事

| # | 能力 | 内容 |
|---|------|------|
| 1 | 看战略 | 诊断 · **ProdStack** · **GtmStack（客户×渠道前瞻）** · WTP/HTW · BSC · OKR · Doctrine |
| 2 | 看执行 | **4DX 记分板**、V1–V10、假设（含 Cynefin 域）、≤3 预警、承诺 |
| 3 | 看健康 | 四灯、8 KPI、稳健性、趋势 |

---

## 5. 报告与版本（差异化）

- **月报 MON-RPT**、**季报 QTR-REV** → 结构化上传（见 REPORT_FORMATS.md）
- **快照：** `{YYYY}-H1-STRATEGIC` · `{YYYY}-FY-STRATEGIC`
- **对比：** StratDiff **18 类**变化（MVP 8 类 → MVP+ 含 Mintzberg #15–18）· StratRobust **五维 + R6 学习**
