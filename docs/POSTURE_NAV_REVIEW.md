# 战略态势区导航 · 职责边界与合并重构方案

> 触发问题：董事会 A3 为何跳转而非内嵌？罗盘 / 一页纸 / 展望 / 指挥舱 / A3 的拆分逻辑是否"为分而分"？
> 本文基于代码实况（`app/(dashboard)/*/page.tsx`、`app/print/panorama/page.tsx`、`lib/nav/hubs.ts`），先摆事实，再给判断与落地建议。**尚未改动任何代码，供审阅后决策。**

---

## 一、现状事实（每页实际渲染什么）

| 页面 | 路由 | 数据源 | 实际内容 |
|---|---|---|---|
| 指挥舱 | `/command`（在 dashboard 壳内） | `getCommandDeckBundle()` | SCR 一句话态势、推论条、HardBlock 硬阻断、决策编辑、BSC 四满意、StratRobust、FPA 管理报表、B-A-F、**SPBP 情景**、**Top3 StratDiff**、Top 预警、快捷跳转、里程碑/导入（折叠） |
| 战略罗盘 | `/compass` | `getCompassBundle()` | 使命/愿景/5 年终点反推、**假设前提实时审计**、SWOT bridge |
| 一页纸 | `/strategy` | `getStrategyBundle()` | 两个 tab：**「看战略」**（诊断+三栈+OKR）与**「董事会一页纸」** |
| 战略展望 | `/outlook` | `getFinanceBundle()` | 外部环境（交叉链）→ 三层面 H1/H2/H3 → **情景** → 轨迹 → **稳健度** |
| 董事会 A3 | `/print/panorama`（**在 dashboard 壳外**） | `getCommandDeckBundle()`（与指挥舱**同源**） | `data-theme="print"` 全屏打印布局 + 打印/导出 PDF 按钮 |

**关键事实**：A3 全景与指挥舱是**同一份 `getCommandDeckBundle()` 数据**，A3 只是它的"打印皮肤"，不含独立内容。

---

## 二、每页回答什么问题（设计意图轴）

底层确有一条叙事轴，按**时间视角**排列：

- **战略罗盘（终局↩）** — "终点是什么？从 5 年后反推，现在哪些**前提假设**在动摇？"
- **一页纸（现在）** — "我们的战略主张到底是什么？"（plan of record）
- **战略展望（未来）** — "未来几年往哪走？增长如何按 H1/H2/H3 随时间配置？情景与稳健度？"
- **指挥舱（当下运营）** — "此刻集团态势如何？有什么要我立即决策？"
- **董事会 A3（输出物）** — "怎么把整体一张纸交给董事会？"

叙事线：罗盘（为什么/去哪）→ 一页纸（是什么）→ 展望（未来轨迹）；指挥舱是"现在运营面板"，A3 是"导出物"。

## 三、重叠矩阵（诚实指出冗余）

| 重叠内容 | 出现位置 | 判断 |
|---|---|---|
| **"董事会一页纸/A3"** | ①指挥舱按钮 ②`/strategy` 的 onepager tab ③`/print/panorama` | 🔴 **三处同名、职责重叠** — 最大混乱源 |
| **SPBP 情景** | 指挥舱 · 展望 | 🟡 指挥舱放预览、展望放全量，尚可接受但需明确主次 |
| **StratRobust 稳健度** | 指挥舱 · 展望 | 🟡 同上 |
| **StratDiff 版本变化** | 指挥舱 Top3 · `/versions` 全量 | 🟢 Top3→全量的合理下钻 |
| **假设前提** | 罗盘（审计）· 展望（外部环境交叉链） | 🟢 展望只做交叉链，不重复 |

**结论**：不是全面"为分而分"，叙事轴成立；但 **A3/一页纸命名与职责三头重叠**确实是过度拆分，且 A3 作为导航平级项不合理。

---

## 四、重点行动项：A3 改为「内嵌预览 + 导出」（已获认可）

### 现状问题
`lib/nav/hubs.ts` 把 `/print/panorama` 作为态势 hub 的平级子项。点击 tab 直接跳到一个**脱离 App 外壳的裸打印页**，突兀、易迷路。而它本就是指挥舱数据的打印态。

### 目标形态
1. **从导航平级项移除** `/print/panorama`（`lib/nav/hubs.ts` 态势 hub children 去掉该条）。
2. 指挥舱内新增「董事会视图」区块：内嵌 `PanoramaPrintLayout` 预览（复用现成组件，同源数据，零新查询）。
3. 预览区右上角放 **【打印】【导出 PDF】** 按钮 → 仅点按钮时才进 `/print/panorama` 裸页（保留打印能力）。
4. `/print/panorama` 路由**保留**（打印/PDF 必须要裸页），只是不再当导航入口。

### 影响面（小、低风险）
- 改 `lib/nav/hubs.ts`（含 `flattenNavLinks` ⌘K 面板，有测试覆盖）。
- 指挥舱 `page.tsx` 现有按钮「董事会一页纸」→ 改为锚点滚动到内嵌区块或直接就是导出按钮。
- 不动 `getCommandDeckBundle`、不动 `PanoramaPrintLayout`。

## 五、合并 / 保留建议（分档）

### 立即建议
1. **A3 内嵌+导出**（见 §四）。
2. **消除"董事会一页纸"命名三头冲突**：统一为——
   - `/strategy` 的 tab 叫「战略主张（看战略）」+「董事会视图（一页纸）」；
   - 指挥舱按钮与 A3 统一叫「董事会 A3 / 导出」；
   - 避免用户在三处看到同一个词却指向不同东西。

### 可选（需你拍板）
3. **指挥舱 vs 展望去重**：明确 SPBP 情景 / StratRobust 的"主场"在展望，指挥舱只保留只读缩略图 + "去展望"链接（现已是 `embedded`，只差文案与主次声明）。

### 建议保留（不要合并）
- 罗盘、一页纸、展望**三页各自独立**——时间视角不同，是清晰的叙事分工，合并反而丢失"终局↩/现在/未来"的认知脚手架。
- `/versions` 与指挥舱 Top3 StratDiff 的下钻关系保留。

## 六、导航副标题建议（降低"为分而分"困惑）

在 HubSubNav 或各页 PageHeader 用一句话点明"回答什么问题"（改动小、零逻辑风险）：

- 罗盘：「终点反推 · 前提假设在动摇吗？」
- 一页纸：「我们的战略主张是什么」
- 展望：「未来 3–5 年往哪走」
- 指挥舱：「此刻态势 · 待决策」
